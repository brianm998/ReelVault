# ReelVault

Кросплатформний застосунок для каталогізації відео, натхненний Lightroom — швидкий, нативний перегляд великих відеотек.

**ReelVault призначений для організації, пошуку та управління відео. Це НЕ відеоредактор.**

## Огляд

ReelVault допомагає вам:

- **Переглядати** тисячі відео у гнучкій віртуалізованій сітці з налаштовуваним розміром мініатюр.
- **Скрабувати** у стилі Lightroom: наведіть курсор на мініатюру та переміщуйте вліво↔вправо для попереднього перегляду кадрів по таймлайну.
- **Групувати** пов'язані варіанти (наприклад, експорт 4K і 1080p з одного джерела) у стопки у стилі Lightroom; позначити один як бажаний для сітки та відкриття.
- **Знаходити** контент за допомогою повнотекстового пошуку, фільтрації тегів та випадних меню фільтрів по полях (камера, об'єктив, кодек, рік зйомки, ключове слово).
- **Інспектувати** детальні метадані: кодек, роздільну здатність, FPS, бітрейт, колірний простір, HDR, EXIF, GPS, модель камери/об'єктива.
- **Організовувати** за допомогою довільних нотаток, ключових слів та операцій з множинним вибором.
- **Передавати** кліпи зовнішнім редакторам перетягуванням — перетягніть одну або кілька карток прямо з сітки до DaVinci Resolve, Final Cut Pro, Premiere Pro або будь-якого застосунку, що приймає файли.
- Робочі процеси **з кількома каталогами**: відкриття / закриття / перемикання каталогів SQLite з меню «Файл», із списком останніх каталогів та заголовками вікон для кожного каталогу.

## Архітектура

```
Desktop / macOS clients          iOS / Android clients
   ↓ gRPC over loopback             ↓ gRPC + HTTPS media over the LAN
   │                                │ (mDNS/NSD discovery · pinned TLS · paired)
   └───────────────┬────────────────┘
                   ↓
        Rust Backend Daemon (reelvault-core)
                   ↓
        SQLite Catalog + FFmpeg/FFprobe + Filesystem
```

- **Rust core** (`core/`) — gRPC-демон на основі Tonic. Відповідає за каталог SQLite, витягування метаданих FFprobe, генерацію мініатюр і скрабових кадрів, сканування/індексування, пошук та агрегацію фільтрів. Підтримує гаряче перемикання активного каталогу під час виконання через RPC: `OpenCatalog` / `CloseCatalog` / `GetCurrentCatalog`, тому один процес демона може обслуговувати кілька бібліотек протягом свого терміну служби.

- **Kotlin Compose desktop-клієнт** (`kotlin-desktop/`) — UI Compose Multiplatform. Автоматично виявляє запущений демон на `127.0.0.1:50051`; якщо жодний не запущений, сам запускає вбудований демон (з переходом на порт, призначений ОС, якщо 50051 зайнятий).

- **SwiftUI macOS-клієнт** (`macos/`) — нативний застосунок macOS з повним паритетом функцій, таким же потоком автозапуску, справжнім меню «Файл» macOS (група Commands) та реактивним заголовком вікна, що відстежує відкритий каталог.

- **SwiftUI iOS-клієнт** (`ios/`) — застосунок iPhone / iPad **лише для віддаленого підключення**. Не має доступу до локальних файлів і не містить вбудованого демона: знаходить демон через Wi‑Fi (mDNS), підключається через TLS-канал з закріпленим відбитком після одноразового парування, переглядає через gRPC і **стримить** відео (HLS зі зниженою роздільною здатністю) з медіасервера демона. Замінює перетягування в редактор на листок обміну iOS та додає завантаження з «Фото» / «Файли». Дивіться [`ios/README.md`](ios/README.md).

- **Kotlin Compose Android client** (`android/`) — A **remote-only**
  Android phone / tablet app. Connects to a daemon over the LAN (NSD
  discovery), streams video via ExoPlayer, and replaces editor drag-out with
  the Android share intent. Also embeds the full Rust core for on-device local
  library access — browse, catalog, and upload footage directly from the
  device. See [`android/README.md`](android/README.md).

- **ReelVaultKit** (`kit/`) — локальний пакет SwiftPM зі спільним Swift-кодом, що використовується **обома** клієнтами Apple: моделі, view-моделі, gRPC-клієнт, пошук, закріплений TLS та рівень кешування/стримінгу медіа.

- **Каталог SQLite** — база даних у режимі WAL з FTS5 для повнотекстового пошуку. Схема знаходиться в [`core/schema.sql`](core/schema.sql).

> **Мініатюри ProRes RAW мають якість лише на macOS.** ffmpeg не може декодувати ProRes RAW (Atomos S-Log3 / S-Gamut), тому на **macOS** демон декодує його через QuickLook / AVFoundation — правильні кольори і справжній покадровий скрабінг. На **Linux / Windows** такого декодера немає, тому демон переходить на ffmpeg: більш плоскі/темні кадри і один кадр скрабінгу, що повторюється. Rust core компілюється однаково на всіх трьох платформах — AVFoundation ніколи не підключається до нього. Деталі: [`core/README.md`](core/README.md) (шляхи збірки + декодування) та [`macos/README.md`](macos/README.md) (macOS-клієнт). Усі інші кодеки обробляються ffmpeg однаково скрізь.

## Стан проєкту

**MVP функціонує на macOS та Compose Desktop.** Обидва клієнти мають однаковий набір функцій; macOS-клієнт додає нативні команди рядка меню та запуск редакторів через NSWorkspace. **iOS-клієнт лише для віддаленого підключення** (iPhone / iPad) підключається до демона через локальну мережу та стримить відео — перегляд, інспекція, стопки, обмін та завантаження; дивіться [`ios/README.md`](ios/README.md).

## Початок роботи

### Передумови

- **Rust** (рекомендовано 1.75+) — для збірки основного демона.
- **FFmpeg / FFprobe** — повинен бути у `PATH`. Використовується для витягування метаданих і генерації мініатюр/скрабових кадрів.
- **JDK 17+** + Gradle (обгортка включена) — для Kotlin desktop-клієнта.
- **Swift 5.9+ / Xcode 15+** — для macOS-клієнта.
- **Xcode 16+ (iOS 18 SDK) + [XcodeGen](https://github.com/yonaskolb/XcodeGen)**
  (`brew install xcodegen`) — для iOS-клієнта.

Дивіться [`SETUP.md`](SETUP.md) для отримання інструкцій з встановлення для конкретних платформ.

### Збірка основного демона

```bash
cd core
cargo build --release
```

Двійковий файл розташовується у `core/target/release/reelvault-core`. Запустіть його безпосередньо, якщо хочете керувати ним самостійно, або дозвольте одному з клієнтів запустити його для вас при першому запуску:

```bash
# За замовчуванням — використовує каталог платформи за замовчуванням на стандартному порту.
./target/release/reelvault-core

# Запуск без каталогу (клієнти використовують цей режим); виводить прив'язаний порт.
./target/release/reelvault-core --no-catalog --port 0

# Відкриття конкретного каталогу при запуску.
./target/release/reelvault-core --db-path /path/to/library.db
```

Демон виводить стабільний рядок `REELVAULT_LISTENING_ON=127.0.0.1:N` у stdout, який клієнти аналізують для виявлення призначеного порту.

### Запуск Kotlin Compose desktop-клієнта

```bash
cd kotlin-desktop
./gradlew run
```

При першому запуску клієнт перевіряє `127.0.0.1:50051` і — якщо нічого не слухає — запускає вбудований демон. Порядок пошуку місця збірки:

1. `$REELVAULT_CORE_BIN` (абсолютний шлях до виконуваного файлу демона)
2. Двійковий файл поруч із jar-файлом застосунку
3. `core/target/release/reelvault-core` або `core/target/debug/reelvault-core` у дереві розробки
4. `reelvault-core` у `PATH`

Для розробки достатньо `cargo build` всередині `core/`, і клієнт підхопить debug-двійковий файл.

### Запуск macOS SwiftUI-клієнта

```bash
cd macos
swift run
```

Той самий потік автозапуску, той самий порядок пошуку двійкового файлу (плюс внутрішній шлях `Resources/reelvault-core` у пакеті для підписаних пакетів застосунків). Використовуйте `⌘O` для відкриття каталогу та `⇧⌘W` для його закриття; список останніх знаходиться у `File → Open Recent`.

### Запуск iOS SwiftUI-клієнта

iOS-клієнт — **лише для віддаленого підключення** — підключається до демона через локальну мережу замість запуску власного. Запустіть демон у режимі remote на машині в тій самій Wi‑Fi-мережі:

```bash
reelvault-core --remote --db-path /path/to/library.db --import-dir /path/to/imports
```

Потім згенеруйте проєкт Xcode (`.xcodeproj` не комітиться) і зберіть:

```bash
cd ios
make project          # requires XcodeGen: brew install xcodegen
make build            # iOS Simulator; or open ReelVault.xcodeproj to run on a device
```

При першому запуску застосунок знаходить демон через mDNS, ви авторизуєте пристрій одного разу 6-значним кодом парування (згенеруйте його з **File → Pair a New Device** у desktop-клієнті або з логів демона), а потім переглядайте + стримте. Потрібні **iOS 18+** та **Xcode 16+**. Повні деталі, включно з моделями стримінгу та парування, знаходяться в [`ios/README.md`](ios/README.md).
