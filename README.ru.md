# ReelVault

Кроссплатформенное приложение для каталогизации видео, вдохновлённое Lightroom — быстрый,
нативный просмотр больших видеотек.

**ReelVault предназначен для организации, обнаружения и управления видеофайлами. Это НЕ видеоредактор.**

## Обзор

ReelVault позволяет вам:

- **Просматривать** тысячи видео в отзывчивой виртуализированной сетке с
  настраиваемым размером миниатюр.
- **Скраббировать** в стиле Lightroom: наведите курсор на миниатюру и двигайте влево↔вправо,
  чтобы предварительно просмотреть кадры по всей временной шкале.
- **Группировать** связанные варианты (например, экспорты 4K и 1080p из одного источника)
  в стеки в стиле Lightroom; отмечать один как предпочтительный для сетки и открытия.
- **Находить** контент с помощью полнотекстового поиска, фильтрации по тегам и выпадающих
  фильтров по полям (камера, объектив, кодек, год съёмки, ключевое слово).
- **Просматривать** подробные метаданные: кодек, разрешение, FPS, битрейт, цветовое пространство,
  HDR, EXIF, GPS, модель камеры/объектива.
- **Организовывать** с помощью произвольных заметок, ключевых слов и операций с множественным выбором.
- **Передавать** клипы во внешние редакторы путём перетаскивания — перетащите одну или несколько
  карточек прямо из сетки в DaVinci Resolve, Final Cut Pro, Premiere Pro
  или любое приложение, принимающее файлы.
- **Работать с несколькими каталогами**: открывать / закрывать / переключаться между каталогами SQLite
  через меню «Файл», со списком недавних каталогов и заголовками окон для каждого каталога.

## Архитектура

```
Desktop / macOS clients          iOS / Android clients
   ↓ gRPC over loopback             ↓ gRPC + HTTPS media over the LAN
   │                                │ (mDNS/NSD discovery · pinned TLS · paired)
   └───────────────┬────────────────┘
                   ↓
        Rust Backend Daemon (reelvault-core)
                   ↓
        SQLite Catalog + FFmpeg/FFprobe + Filesystem
```

- **Rust core** (`core/`) — gRPC-демон на основе Tonic. Управляет каталогом SQLite,
  извлечением метаданных FFprobe, генерацией миниатюр и кадров скраббинга,
  сканированием/индексированием, поиском и агрегацией фильтров. Поддерживает горячую замену
  активного каталога во время работы через RPC `OpenCatalog` / `CloseCatalog` /
  `GetCurrentCatalog`, поэтому один процесс демона может обслуживать несколько
  библиотек в течение всего своего срока работы.

- **Kotlin Compose desktop client** (`kotlin-desktop/`) — UI на Compose Multiplatform.
  Автоматически обнаруживает запущенный демон на `127.0.0.1:50051`; если он не запущен,
  самостоятельно запускает встроенный демон (используя порт, назначенный ОС, если
  50051 занят).

- **SwiftUI macOS client** (`macos/`) — нативное macOS-приложение с полным набором функций,
  тем же потоком автозапуска, настоящим меню «Файл» в стиле macOS (группа Commands) и
  реактивным заголовком окна, отслеживающим открытый каталог.

- **SwiftUI iOS client** (`ios/`) — **только удалённый** клиент для iPhone / iPad.
  Не имеет доступа к локальным файлам и не содержит встроенного демона: обнаруживает
  демон через Wi‑Fi (mDNS), подключается по TLS-каналу с привязкой по отпечатку после
  однократной процедуры сопряжения, просматривает данные через gRPC и **транслирует**
  видео (масштабированный HLS) с медиасервера демона. Заменяет перетаскивание в редактор
  на системный лист общего доступа iOS и добавляет загрузку из «Фото» / Files.
  См. [`ios/README.md`](ios/README.md).

- **Kotlin Compose Android client** (`android/`) — A **remote-only**
  Android phone / tablet app. Connects to a daemon over the LAN (NSD
  discovery), streams video via ExoPlayer, and replaces editor drag-out with
  the Android share intent. Also embeds the full Rust core for on-device local
  library access — browse, catalog, and upload footage directly from the
  device. See [`android/README.md`](android/README.md).

- **ReelVaultKit** (`kit/`) — локальный SwiftPM-пакет общего Swift-кода, используемого
  **обоими** клиентами Apple: модели, view-модели, gRPC-клиент, обнаружение,
  привязанный TLS и слой кэширования/потоковой передачи медиа.

- **Каталог SQLite** — база данных в режиме WAL с FTS5 для полнотекстового поиска.
  Схема находится в [`core/schema.sql`](core/schema.sql).

> **Миниатюры ProRes RAW доступны только на macOS.** ffmpeg не может декодировать
> ProRes RAW (Atomos S-Log3 / S-Gamut), поэтому на **macOS** демон декодирует его
> через QuickLook / AVFoundation — с правильной цветопередачей и точным покадровым
> скраббингом. На **Linux / Windows** такого декодера нет, поэтому демон использует
> ffmpeg: более плоские/тёмные кадры и единственный повторяющийся кадр скраббинга.
> Rust core собирается одинаково на всех трёх платформах — AVFoundation
> никогда не компонуется с ним. Подробности: [`core/README.md`](core/README.md)
> (пути сборки и декодирования) и [`macos/README.md`](macos/README.md) (macOS-клиент).
> Все остальные кодеки обрабатываются ffmpeg одинаково везде.

## Статус проекта

**MVP работает на macOS и Compose Desktop.** Оба клиента имеют одинаковый набор функций;
macOS-клиент добавляет нативные команды в строке меню и запуск редакторов через NSWorkspace.
**Клиент iOS только для удалённого подключения** (iPhone / iPad) подключается к демону
по локальной сети и транслирует видео — просмотр, инспекция, стеки, общий доступ и
загрузка; см. [`ios/README.md`](ios/README.md).

## Начало работы

### Требования

- **Rust** (рекомендуется 1.75+) — для сборки основного демона.
- **FFmpeg / FFprobe** — должны быть в `PATH`. Используются для извлечения метаданных
  и генерации миниатюр/кадров скраббинга.
- **JDK 17+** + Gradle (обёртка включена) — для Kotlin-клиента на рабочем столе.
- **Swift 5.9+ / Xcode 15+** — для macOS-клиента.
- **Xcode 16+ (iOS 18 SDK) + [XcodeGen](https://github.com/yonaskolb/XcodeGen)**
  (`brew install xcodegen`) — для iOS-клиента.

Инструкции по установке для конкретных платформ см. в [`SETUP.md`](SETUP.md).

### Сборка основного демона

```bash
cd core
cargo build --release
```

Бинарный файл окажется по пути `core/target/release/reelvault-core`. Запустите его
напрямую, если хотите управлять им самостоятельно, или просто дайте одному из клиентов
запустить его за вас при первом запуске:

```bash
# По умолчанию — использовать каталог платформы на порту по умолчанию.
./target/release/reelvault-core

# Запустить без каталога (этот режим используют клиенты); вывести занятый порт.
./target/release/reelvault-core --no-catalog --port 0

# Открыть конкретный каталог при запуске.
./target/release/reelvault-core --db-path /path/to/library.db
```

Демон выводит стабильную строку `REELVAULT_LISTENING_ON=127.0.0.1:N` в stdout,
которую клиенты разбирают для обнаружения назначенного порта.

### Запуск Kotlin Compose desktop client

```bash
cd kotlin-desktop
./gradlew run
```

При первом запуске клиент проверяет `127.0.0.1:50051` и — если никто не слушает —
запускает встроенный демон. Порядок поиска расположения сборки:

1. `$REELVAULT_CORE_BIN` (абсолютный путь к исполняемому файлу демона)
2. Бинарный файл рядом с jar-файлом приложения
3. `core/target/release/reelvault-core` или `core/target/debug/reelvault-core`
   в дереве разработки
4. `reelvault-core` в `PATH`

Для разработки достаточно выполнить `cargo build` внутри `core/`, и клиент
автоматически найдёт отладочный бинарный файл.

### Запуск SwiftUI macOS client

```bash
cd macos
swift run
```

Тот же поток автозапуска, тот же порядок поиска бинарного файла (с добавлением пути
`Resources/reelvault-core` внутри бандла, используемого подписанными бандлами приложений).
Используйте `⌘O` для открытия каталога и `⇧⌘W` для его закрытия; список недавних
находится в `File → Open Recent`.

### Запуск SwiftUI iOS client

iOS-клиент работает **только удалённо** — он подключается к демону по локальной сети,
а не запускает его самостоятельно. Запустите демон в режиме удалённого доступа на машине
в той же сети Wi‑Fi:

```bash
reelvault-core --remote --db-path /path/to/library.db --import-dir /path/to/imports
```

Затем создайте проект Xcode (`.xcodeproj` не хранится в репозитории) и выполните сборку:

```bash
cd ios
make project          # requires XcodeGen: brew install xcodegen
make build            # iOS Simulator; or open ReelVault.xcodeproj to run on a device
```

При первом запуске приложение обнаруживает демон через mDNS, вы один раз авторизуете
устройство с помощью 6-значного кода сопряжения (сгенерируйте его из меню
**File → Pair a New Device** в десктопном клиенте или из лога демона), после чего
можно просматривать и транслировать видео.
Требуется **iOS 18+** и **Xcode 16+**. Полные сведения, включая модель потоковой передачи
и сопряжения, см. в [`ios/README.md`](ios/README.md).
