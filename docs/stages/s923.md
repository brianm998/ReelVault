# s923: Contain catalog sync

Summary: Hid catalog sync behind one flag (off) in kit and shared across all four clients, stopped iOS/Android auto-sync, and made the Swift push/pull scaffold throw instead of marking jobs done.

Platform notes: the flag is `CatalogSyncFeature.isEnabled` (kit) and `CatalogSyncFeature.ENABLED` (shared). iOS and Android also stop background auto-sync (Android cancels the previously scheduled WorkManager job). The real transfer path is audit item O2.
