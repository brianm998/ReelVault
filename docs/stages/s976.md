# s976: DB work off the async workers; atomic bulk edits

Summary: Simple catalog handlers (tags, collections, notes/ratings, groups, proxies, locations, delete_video, auto_group) now run via run_blocking; tag/untag/collection bulk edits are one transaction each, and ListLibraryLocations uses one grouped counting query. Handlers that also spawn or await (scan, proxy generation, catalog open/close, sync, watch settings, thumbnails) still touch the db inline and remain for a follow-up.
