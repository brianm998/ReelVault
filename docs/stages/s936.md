# s936: Deadlines for ffprobe/ffmpeg subprocesses

Summary: Added `ffmpeg::run_with_timeout` (kill + reap on expiry) and routed every ffprobe/ffmpeg/qlmanage/rv-frameshot call through it so a stalled read can no longer wedge a worker or ffmpeg permit.
