# s920: Harden LAN pairing and token checks

Summary: Pairing codes now die on the 6th wrong PIN, `/pair*` endpoints are rate-limited per client, `/pair/start` no longer replaces a pending code, and token checks run from memory (no SQLite write) with 503/UNAVAILABLE when the database can't be read.

Also: constant-time PIN compare, `device_name` capped at 64 chars, `pairing.txt` and `key.pem` written 0600, `last_seen` flushed every 5 minutes off the request path. Wire format is unchanged, so PairingClient.swift / PairingClient.kt need no change (the 429 on `/pair*` is the only new status).
