# ReelVault

Lightroom থেকে অনুপ্রাণিত একটি ক্রস-প্ল্যাটফর্ম ভিডিও ক্যাটালগিং অ্যাপ্লিকেশন — বড় ভিডিও লাইব্রেরি দ্রুত এবং স্থানীয়ভাবে ব্রাউজ করুন।

**ReelVault ভিডিও সংগঠিত করতে, আবিষ্কার করতে এবং পরিচালনা করতে ব্যবহৃত হয়। এটি ভিডিও এডিটর নয়।**

## সংক্ষিপ্ত বিবরণ

ReelVault আপনাকে সাহায্য করে:

- **ব্রাউজ** করুন হাজার হাজার ভিডিও একটি রেসপন্সিভ, ভার্চুয়ালাইজড গ্রিডে যেখানে থাম্বনেইল সাইজ সামঞ্জস্যযোগ্য।
- **স্ক্রাব** করুন Lightroom-স্টাইলে: একটি থাম্বনেইলে হোভার করুন এবং টাইমলাইন জুড়ে ফ্রেম প্রিভিউ করতে বামে↔ডানে স্লাইড করুন।
- **গ্রুপ** করুন সম্পর্কিত ভেরিয়েন্টস (যেমন একই সোর্সের 4K এবং 1080p এক্সপোর্ট) Lightroom-স্টাইল স্ট্যাকে; গ্রিড এবং খোলার জন্য একটিকে পছন্দের হিসেবে চিহ্নিত করুন।
- **আবিষ্কার** করুন কন্টেন্ট পূর্ণ-টেক্সট অনুসন্ধান, ট্যাগ ফিল্টারিং, এবং প্রতি-ফিল্ড ফিল্টার ড্রপডাউন (ক্যামেরা, লেন্স, কোডেক, ক্যাপচার বছর, কীওয়ার্ড) এর মাধ্যমে।
- **পরীক্ষা** করুন বিস্তারিত মেটাডেটা: কোডেক, রেজোলিউশন, FPS, বিটরেট, কালার স্পেস, HDR, EXIF, GPS, ক্যামেরা/লেন্স মডেল।
- **সংগঠিত** করুন মুক্ত-ফর্ম নোট, কীওয়ার্ড, এবং মাল্টি-সিলেক্ট অপারেশন সহ।
- **হ্যান্ড অফ** করুন ক্লিপস বাহ্যিক এডিটরে ড্র্যাগ-অ্যান্ড-ড্রপের মাধ্যমে — গ্রিড থেকে সরাসরি DaVinci Resolve, Final Cut Pro, Premiere Pro বা যেকোনো অ্যাপে এক বা একাধিক কার্ড ড্র্যাগ করুন।
- **মাল্টি-ক্যাটালগ** ওয়ার্কফ্লো: ফাইল মেনু থেকে SQLite ক্যাটালগ খুলুন / বন্ধ করুন / সুইচ করুন।

## আর্কিটেকচার

```
Desktop / macOS clients          iOS / Android clients
   ↓ gRPC over loopback             ↓ gRPC + HTTPS media over the LAN
   │                                │ (mDNS/NSD discovery · pinned TLS · paired)
   └───────────────┬────────────────┘
                   ↓
        Rust Backend Daemon (reelvault-core)
                   ↓
        SQLite Catalog + FFmpeg/FFprobe + Filesystem
```

- **Rust কোর** (`core/`) — Tonic-ভিত্তিক gRPC ডেমন। SQLite ক্যাটালগ, FFprobe মেটাডেটা এক্সট্র্যাকশন, থাম্বনেইল এবং স্ক্রাব-ফ্রেম জেনারেশন, স্ক্যান/ইন্ডেক্সিং, অনুসন্ধান এবং ফিল্টার অ্যাগ্রিগেশন পরিচালনা করে।

- **Kotlin Compose ডেস্কটপ ক্লায়েন্ট** (`desktop/`) — Compose Multiplatform UI। `127.0.0.1:50051`-এ চলমান ডেমন স্বয়ংক্রিয়ভাবে সনাক্ত করে; কিছু না চললে বান্ডেলড ডেমন নিজেই চালু করে।

- **SwiftUI macOS ক্লায়েন্ট** (`macos/`) — ফিচার-প্যারিটি নেটিভ macOS অ্যাপ।

- **SwiftUI iOS ক্লায়েন্ট** (`ios/`) — শুধুমাত্র-রিমোট iPhone / iPad অ্যাপ। LAN-এ Wi‑Fi (mDNS) এর মাধ্যমে ডেমন আবিষ্কার করে, gRPC-এর মাধ্যমে ব্রাউজ করে, এবং ডেমনের মিডিয়া সার্ভার থেকে ভিডিও স্ট্রিম করে। [`ios/README.md`](ios/README.md) দেখুন।

- **Kotlin Compose Android ক্লায়েন্ট** (`android/`) — শুধুমাত্র-রিমোট Android ফোন / ট্যাবলেট অ্যাপ। LAN-এর উপর ডেমনের সাথে সংযুক্ত হয় (NSD আবিষ্কার), ExoPlayer-এর মাধ্যমে ভিডিও স্ট্রিম করে, এবং অন-ডিভাইস লোকাল লাইব্রেরি অ্যাক্সেসের জন্য সম্পূর্ণ Rust কোর এমবেড করে। [`android/README.md`](android/README.md) দেখুন।

- **ReelVaultKit** (`kit/`) — একটি স্থানীয় SwiftPM প্যাকেজ যা **উভয়** Apple ক্লায়েন্ট ব্যবহার করে: মডেল, ভিউ-মডেল, gRPC ক্লায়েন্ট, আবিষ্কার, পিনড TLS, এবং মিডিয়া ক্যাশিং/স্ট্রিমিং লেয়ার।

- **SQLite ক্যাটালগ** — পূর্ণ-টেক্সট অনুসন্ধানের জন্য FTS5 সহ WAL-মোড ডেটাবেস।

## প্রকল্পের অবস্থা

**MVP সমস্ত চারটি ক্লায়েন্টে কার্যকর।** macOS এবং Kotlin Compose ডেস্কটপ ক্লায়েন্ট সম্পূর্ণ ফিচার সেট শেয়ার করে। **iOS ক্লায়েন্ট** (iPhone / iPad) এবং **Android ক্লায়েন্ট** প্রত্যেকে LAN-এর উপর ডেমনের সাথে সংযুক্ত হয় এবং ভিডিও স্ট্রিম করে। উভয় মোবাইল ক্লায়েন্ট নেটওয়ার্ক সংযোগ ছাড়াই অন-ডিভাইস লোকাল লাইব্রেরি অ্যাক্সেসের জন্য সম্পূর্ণ Rust কোরও এমবেড করে।

## শুরু করা

### পূর্বশর্ত

- **Rust** (1.75+ প্রস্তাবিত) — কোর ডেমন বিল্ড করতে।
- **FFmpeg / FFprobe** — `PATH`-এ থাকতে হবে।
- **JDK 17+** + Gradle — Kotlin ডেস্কটপ ক্লায়েন্টের জন্য।
- **Swift 5.9+ / Xcode 15+** — macOS ক্লায়েন্টের জন্য।
- **Xcode 16+ (iOS 18 SDK) + [XcodeGen](https://github.com/yonaskolb/XcodeGen)** — iOS ক্লায়েন্টের জন্য।

প্ল্যাটফর্ম-নির্দিষ্ট ইনস্টল নির্দেশাবলীর জন্য [`SETUP.md`](SETUP.md) দেখুন।

### কোর ডেমন বিল্ড করুন

```bash
cd core
cargo build --release
```

```bash
./target/release/reelvault-core
./target/release/reelvault-core --no-catalog --port 0
./target/release/reelvault-core --db-path /path/to/library.db
```

### Kotlin Compose ডেস্কটপ ক্লায়েন্ট চালান

```bash
cd desktop
./gradlew run
```

### macOS SwiftUI ক্লায়েন্ট চালান

```bash
cd macos
swift run
```

### iOS SwiftUI ক্লায়েন্ট চালান

```bash
reelvault-core --remote --db-path /path/to/library.db --import-dir /path/to/imports
cd ios
make project
make build
```

### Android ক্লায়েন্ট চালান

```bash
cd android
./build-core.sh
./gradlew assembleDebug
```
