# ReelVault

ایک کراس پلیٹ فارم ویڈیو کیٹلاگنگ ایپلیکیشن جو Lightroom سے متاثر ہے — بڑی ویڈیو لائبریریوں کو تیز اور مقامی طریقے سے براؤز کریں۔

**ReelVault ویڈیوز کو منظم کرنے، دریافت کرنے اور انتظام کرنے کے لیے ہے۔ یہ ویڈیو ایڈیٹر نہیں ہے۔**

## جائزہ

ReelVault آپ کی مدد کرتا ہے:

- **براؤز** کریں ہزاروں ویڈیوز کو ایک ریسپانسو، ورچوئلائزڈ گرڈ میں جس میں تھمب نیل سائز ایڈجسٹ ہوتا ہے۔
- **اسکرب** کریں Lightroom طرز میں: تھمب نیل پر ہوور کریں اور ٹائم لائن پر فریمز دیکھنے کے لیے بائیں↔دائیں سلائڈ کریں۔
- **گروپ** کریں متعلقہ ویریئنٹس (مثلاً ایک ہی سورس کی 4K اور 1080p ایکسپورٹس) کو Lightroom طرز کے اسٹیکس میں؛ ایک کو گرڈ اور کھولنے کے لیے ترجیحی بنائیں۔
- **دریافت** کریں مواد کو مکمل متن تلاش، ٹیگ فلٹرنگ، اور فی فیلڈ فلٹر ڈراپ ڈاؤنز (کیمرہ، لینس، کوڈیک، کیپچر سال، کی ورڈ) کے ذریعے۔
- **جانچیں** تفصیلی میٹاڈیٹا: کوڈیک، ریزولیوشن، FPS، بٹ ریٹ، کلر اسپیس، HDR، EXIF، GPS، کیمرہ/لینس ماڈل۔
- **منظم** کریں آزادانہ نوٹس، کی ورڈز، اور ملٹی سلیکٹ آپریشنز کے ساتھ۔
- **ہینڈ آف** کریں کلپس کو بیرونی ایڈیٹرز میں ڈریگ اینڈ ڈراپ کے ذریعے — ایک یا زیادہ کارڈز کو گرڈ سے براہ راست DaVinci Resolve، Final Cut Pro، Premiere Pro یا کسی بھی ایپ میں ڈریگ کریں جو فائل ڈراپس قبول کرتی ہو۔
- **ملٹی کیٹلاگ** ورک فلوز: فائل مینو سے SQLite کیٹلاگز کھولیں / بند کریں / سوئچ کریں، حالیہ کیٹلاگز کی فہرست اور فی کیٹلاگ ونڈو ٹائٹلز کے ساتھ۔

## آرکیٹیکچر

```
Desktop / macOS clients          iOS / Android clients
   ↓ gRPC over loopback             ↓ gRPC + HTTPS media over the LAN
   │                                │ (mDNS/NSD discovery · pinned TLS · paired)
   └───────────────┬────────────────┘
                   ↓
        Rust Backend Daemon (reelvault-core)
                   ↓
        SQLite Catalog + FFmpeg/FFprobe + Filesystem
```

- **Rust کور** (`core/`) — Tonic پر مبنی gRPC ڈیمن۔ SQLite کیٹلاگ، FFprobe میٹاڈیٹا اکسٹریکشن، تھمب نیل اور اسکرب فریم جنریشن، اسکین/انڈیکسنگ، تلاش اور فلٹر ایگریگیشن کا انتظام کرتا ہے۔

- **Kotlin Compose ڈیسک ٹاپ کلائنٹ** (`desktop/`) — Compose Multiplatform UI۔ `127.0.0.1:50051` پر چلنے والے ڈیمن کو خودکار طریقے سے ڈیٹیکٹ کرتا ہے؛ اگر کوئی نہیں چل رہا تو بنڈل ڈیمن خود شروع کرتا ہے۔

- **SwiftUI macOS کلائنٹ** (`macos/`) — فیچر پیرٹی نیٹو macOS ایپ۔

- **SwiftUI iOS کلائنٹ** (`ios/`) — صرف ریموٹ iPhone / iPad ایپ۔ LAN پر Wi-Fi (mDNS) کے ذریعے ڈیمن دریافت کرتی ہے، گرڈ کو gRPC کے ذریعے براؤز کرتی ہے، اور ڈیمن کے میڈیا سرور سے ویڈیو سٹریم کرتی ہے۔ ایڈیٹر ڈریگ آؤٹ کو iOS شیئر شیٹ سے بدلتی ہے۔ [`ios/README.md`](ios/README.md) دیکھیں۔

- **Kotlin Compose Android کلائنٹ** (`android/`) — صرف ریموٹ Android فون / ٹیبلٹ ایپ۔ LAN پر ڈیمن سے جڑتی ہے (NSD دریافت)، ExoPlayer کے ذریعے ویڈیو سٹریم کرتی ہے، اور آن ڈیوائس لوکل لائبریری تک رسائی کے لیے مکمل Rust کور ایمبیڈ کرتی ہے۔ [`android/README.md`](android/README.md) دیکھیں۔

- **ReelVaultKit** (`kit/`) — مشترکہ Swift کا ایک لوکل SwiftPM پیکج جو **دونوں** Apple کلائنٹس استعمال کرتے ہیں: ماڈلز، ویو ماڈلز، gRPC کلائنٹ، دریافت، پنڈ TLS، اور میڈیا کیشنگ/اسٹریمنگ پرت۔

- **SQLite کیٹلاگ** — مکمل متن تلاش کے لیے FTS5 کے ساتھ WAL موڈ ڈیٹابیس۔

## پروجیکٹ کی حیثیت

**MVP تمام چاروں کلائنٹس پر فعال ہے۔** macOS اور Kotlin Compose ڈیسک ٹاپ کلائنٹس مکمل فیچر سیٹ شیئر کرتے ہیں۔ **iOS کلائنٹ** (iPhone / iPad) اور **Android کلائنٹ** ہر ایک LAN پر ڈیمن سے جڑتے ہیں اور ویڈیو سٹریم کرتے ہیں۔ دونوں موبائل کلائنٹس آن ڈیوائس لوکل لائبریری تک رسائی کے لیے مکمل Rust کور ایمبیڈ بھی کرتے ہیں۔

## شروع کرنا

### پیشگی ضروریات

- **Rust** (1.75+ تجویز کردہ) — کور ڈیمن بلڈ کرنے کے لیے۔
- **FFmpeg / FFprobe** — `PATH` میں ہونا ضروری ہے۔
- **JDK 17+** + Gradle — Kotlin ڈیسک ٹاپ کلائنٹ کے لیے۔
- **Swift 5.9+ / Xcode 15+** — macOS کلائنٹ کے لیے۔
- **Xcode 16+ (iOS 18 SDK) + [XcodeGen](https://github.com/yonaskolb/XcodeGen)** — iOS کلائنٹ کے لیے۔

پلیٹ فارم مخصوص انسٹال ہدایات کے لیے [`SETUP.md`](SETUP.md) دیکھیں۔

### کور ڈیمن بلڈ کریں

```bash
cd core
cargo build --release
```

```bash
./target/release/reelvault-core
./target/release/reelvault-core --no-catalog --port 0
./target/release/reelvault-core --db-path /path/to/library.db
```

### Kotlin Compose ڈیسک ٹاپ کلائنٹ چلائیں

```bash
cd desktop
./gradlew run
```

### macOS SwiftUI کلائنٹ چلائیں

```bash
cd macos
swift run
```

### iOS SwiftUI کلائنٹ چلائیں

```bash
reelvault-core --remote --db-path /path/to/library.db --import-dir /path/to/imports
cd ios
make project
make build
```

### Android کلائنٹ چلائیں

```bash
cd android
./build-core.sh
./gradlew assembleDebug
```
